# GreenHouse - Invernadero Inteligente

GreenHouse es una aplicación móvil Android desarrollada en Kotlin para el monitoreo y control de un invernadero inteligente.

La aplicación permite visualizar datos asociados a sensores ambientales y controlar actuadores de forma remota mediante Firebase Realtime Database.

## Funcionalidades principales

- Registro de usuarios.
- Inicio y cierre de sesión.
- Verificación de correo electrónico.
- Recuperación de contraseña.
- Edición de nombre, correo y foto de perfil.
- Visualización de temperatura.
- Visualización de humedad ambiental.
- Visualización de humedad del suelo.
- Visualización de luminosidad.
- Visualización del nivel de agua.
- Control remoto de bomba de agua.
- Control remoto de ventilación.
- Sincronización en tiempo real entre dispositivos Android.
- Detección del estado de conexión con Firebase.
- Reglas de acceso y seguridad mediante Firebase Authentication.

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Firebase Authentication
- Firebase Realtime Database
- Material Design
- Git
- GitHub

## Comunicación

La aplicación utiliza conexión a Internet mediante Wi-Fi o datos móviles para comunicarse con Firebase.

Firebase Realtime Database permite sincronizar en tiempo real los datos de sensores y el estado de los actuadores entre distintos dispositivos Android.

## Seguridad

GreenHouse incorpora medidas de seguridad como:

- Autenticación de usuarios mediante Firebase Authentication.
- Verificación de correo electrónico.
- Control de acceso mediante reglas de Firebase Realtime Database.
- Uso de conexiones seguras.
- Permisos mínimos necesarios en Android.
- Protección de datos locales de la aplicación.

## Proyecto académico

Proyecto desarrollado para la asignatura Aplicaciones Móviles para IoT.

El objetivo es implementar una aplicación Android capaz de monitorear y controlar un sistema de invernadero inteligente mediante comunicación inalámbrica y almacenamiento de datos en la nube.
